### 2.2 测试策略

采用**黑盒测试**为主、**灰盒测试**为辅的策略：

- **功能测试**：逐接口验证请求/响应正确性
- **边界测试**：空值、超长值、特殊字符输入验证
- **安全测试**：密码不返回、重复数据拒止、参数范围校验
- **性能测试**：流式问答首字响应时间、并发处理能力
- **回归测试**：修改后全量重跑核心用例

### 2.3 测试原则

1. 每个测试用例独立可重复执行
2. 覆盖正常流程 + 异常流程
3. 先测核心功能（问答），再测辅助功能（管理）
4. 安全相关用例优先级最高

## 3、测试过程

### 3.1 测试环境搭建

1. 启动 Docker 中间件（MySQL 8.0.31 + Redis 7.2）
2. 启动 Ollama 本地大模型（qwen2.5:3b + bge-m3）
3. 执行 `init.sql` 初始化数据库表结构和默认数据
4. 启动 Spring Boot 后端（mvn spring-boot:run）
5. 启动 Vue 3 前端（npm run dev）

### 3.2 测试执行过程

**第一轮测试**：核心功能验证
- 发现前端 SSE 流式解析 BUG，流结束后 buffer 未刷新导致最后几字丢失 → 已修复
- 发现 System Prompt 过于严格导致模型回答截断 → 已优化

**第二轮测试**：回归验证
- 所有核心用例全部通过
- 新增边界测试（空密码、重复用户名、超范围满意度）→ 全部通过

**第三轮测试**：性能基线
- 流式问答首字响应 1.64s，知识库匹配 < 200ms

### 3.3 缺陷记录

| 编号 | 缺陷描述 | 严重程度 | 状态 |
|------|----------|----------|------|
| BUG-01 | SSE 流结束 buffer 未刷新导致回答截断 | 高 | ✅ 已修复 |
| BUG-02 | System Prompt 限制导致回答只说一半 | 高 | ✅ 已修复 |
| BUG-03 | `@JsonIgnore` 阻止密码反序列化 | 中 | ✅ 已修复 |
| BUG-04 | AnythingLLM 缺少 STORAGE_DIR 导致容器崩溃 | 中 | ✅ 已修复 |
| BUG-05 | 嵌入加载阻塞应用启动 | 低 | ✅ 已修复 |
