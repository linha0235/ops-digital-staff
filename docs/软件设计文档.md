# 运维数字员工系统——软件设计文档

## 1、引言

### 1.1 编写目的

本文档旨在详细描述"运维数字员工系统"的总体架构设计、模块划分、接口设计、数据库设计及关键技术方案，为开发人员提供清晰的技术实现指导，为后续维护和扩展提供参考依据。

### 1.2 概要设计

运维数字员工系统采用 **B/S 架构**，前端基于 Vue 3 + Element Plus，后端基于 Spring Boot 3 + MyBatis-Plus，集成 Ollama 本地大模型实现智能问答。系统核心特性：

- **前后端分离**：前端 Vite 开发服务器代理 `/api` 到后端 8080 端口
- **RESTful API**：统一 JSON 返回格式 `{code, msg, data}`
- **SSE 流式通信**：智能问答采用 Server-Sent Events 实现 token 级流式输出
- **三层 RAG 回退**：本地嵌入 → AnythingLLM → Ollama 直连，层层降级

### 1.3 业务流程图

```
用户登录 → 首页仪表盘（查看统计数据）
  │
  ├─ 账号管理 → 增删改查运维人员 → 冻结/解冻
  │
  ├─ 知识库管理 → 新增 FAQ → 自动生成嵌入向量 → 停用/启用
  │                           │
  │                           └─ 同步到 AnythingLLM（可选）
  │
  ├─ 工单管理 → 用户提交工单 → 运维受理 → 处理完成 → 满意度回访
  │
  └─ 智能问答 → 输入问题
                   │
                   ├─ 本地嵌入匹配 → 直接返回知识库答案
                   ├─ AnythingLLM 检索 → 提取高置信度答案
                   └─ Ollama 流式推理 → SSE 打字机输出
```

### 2.2 分层架构说明

| 层次 | 职责 | 技术 |
|------|------|------|
| 表现层 (Controller) | 接收 HTTP 请求，参数校验，调用 Service | Spring MVC, SseEmitter |
| 业务层 (Service) | 业务逻辑编排，CRUD 操作，RAG 流程调度 | Spring Service, MyBatis-Plus |
| 集成层 (Integration) | 外部系统对接（Ollama, AnythingLLM） | HuTool Http, NDJSON |
| 数据层 (Mapper) | 数据库访问 | MyBatis-Plus BaseMapper |
| 基础设施层 | 数据库、缓存、消息 | MySQL, Redis |

### 2.3 技术选型理由

| 技术 | 选型理由 |
|------|----------|
| Spring Boot 3.1.5 | 企业级 Java 框架，生态成熟 |
| MyBatis-Plus 3.5.7 | 简化 CRUD，Lambda 查询，分页插件 |
| Vue 3 Composition API | 更灵活的组件逻辑复用 |
| Element Plus | 企业级 UI 组件库，与 Vue 3 深度集成 |
| Vite | 极速冷启动，HMR 热更新 |
| Ollama | 本地部署，数据不出域，免费使用 |
| bge-m3 | 多语言嵌入模型，中文语义匹配优秀 |
| SSE (非 WebSocket) | 单向流式推送，HTTP 原生支持，无需额外协议 |

## 5、其他

### 5.1 关键技术方案

**本地嵌入 RAG 实现**：
1. 系统启动时异步加载所有启用 FAQ（status=1），调用 bge-m3 生成 1024 维嵌入向量
2. 用户提问时，生成提问嵌入向量，计算与所有 FAQ 向量的余弦相似度
3. 相似度 ≥ 0.75 → 直接返回 FAQ 答案（毫秒级）
4. 相似度 < 0.75 → 取 Top-3 相关 FAQ 作为上下文，调用 Ollama 流式推理

**SSE 流式输出**：
1. 前端使用 `fetch + ReadableStream` 消费 SSE（支持 POST，比 EventSource 更灵活）
2. 后端使用 Spring SseEmitter + 托管线程池异步处理
3. Ollama NDJSON 逐 token 解析 → SSE `data:<content>\n\n` 格式推送
4. 前端 buffer 刷新 + 打字机动画逐字展示

**三层回退策略**：
1. 本地嵌入匹配（无需网络，< 200ms）
2. AnythingLLM 向量检索（可选，增强 RAG）
3. Ollama 直连推理（兜底，永远可用）

### 5.2 配置说明

```yaml
# Ollama 配置（application.yml）

  base-url: http://localhost:11434
  chat-model: qwen2.5:3b
  embedding-model: bge-m3:latest
  embedding-similarity-threshold: 0.75
  num-predict: 2048
```
